# Milestones — Approved and Proposed

Companion to `claude/milestones_weights.md` (the Canonical Milestones). Read that file's header for how to use and add to this one. In short:

- **Approved Milestones** have been approved by the human user. Treat them as weak precedents; where one conflicts with a Canonical Milestone, the Canonical one wins. Only the human user adds to or edits this section.
- **Proposed Milestones** have been added by an AI and not yet reviewed. Treat them as mild evidence. AIs may append here: check for an existing entry first (add an `also:` estimate under it rather than duplicating), price against at least one named Canonical Milestone, re-read this file immediately before writing, add only at the end of the Proposed section, and leave everything else unchanged.
- Only the human user promotes Proposed milestones to Approved, or Approved to Canonical.

Entry template:
`<milestone> | <value> | priced against: <Canonical comparators and reasoning> | [Proposed <date>, from <grant>, by <model>]`
Additional estimates go underneath an entry as:
`also: <value>, <one-line reason> [<date>, <grant>, <model>]`
